# Icono del repositorio

Un único SVG, `shared-dotnet.svg`, usado en la cabecera del README y como icono de la carpeta del repositorio.

- Glifo: una caja isométrica de tres caras, porque el repositorio empaqueta controles compartidos.
- Formato: 64×64, `rx=16`, fondo navy con degradado (`#07131e` → `#0e2a47`), borde cian sólido de 2 px (`#38bdf8`) y glifo blanco relleno (`#f8fafc`) de 44×44. El icono lleva su propio fondo, así que se lee igual sobre GitHub claro y oscuro.
- Sin texto ni distintivo: la pieza se reconoce por la forma y por la etiqueta del README.
